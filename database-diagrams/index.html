Source: Eddict/tmp, pgsql_db.sql

PK: primary key. FK: foreign key. U1, U2, ...: unique key/index groups local to each table (all columns with the same U number form one composite key). ?: nullable. *: inherited column. Gray tables are cross-group references showing referenced and primary-key columns only. Arrows point from foreign-key columns to referenced columns; they are not crow's-foot cardinalities. Dashed arrows indicate PostgreSQL INHERITS, which does not inherit primary/unique/foreign-key constraints. Only declared foreign keys are drawn; column-name similarities do not create relationships. Defaults, checks, triggers, functions, non-unique indexes and function-created runtime tables are not shown.
